# 分散系与胶体

## 分散系

分散系：分散剂+分散质，根据分散质直径分类：

- 溶液，$<1\text{nm}$，表现出均匀、稳定的宏观特征。
- 浊液，$>100 \text{nm}$，表现出不均匀、不稳定的宏观特征，分散质往往会发生沉降或上浮（静置分层）。
- 胶体，$1\sim100 \text{nm}$，在一定条件下能稳定存在（介稳定），并具有不同于溶液和浊液的特性。

## 胶体

性质：

1. **丁达尔现象**。胶体粒子直径小于可见光波长，光入射胶体时会发生光的散射，使用激光笔照射胶体，可以观察到胶体中出现的**一条光亮的通路。**
2. **布朗运动**。悬浮在液体或气体中的微小胶体颗粒因分子热运动而产生的随机无规则运动。
3. 胶体的**稳定性**。主因：电荷排斥；次因：布朗运动。
    1. **胶体粒子**带电是因为其表面能够选择性吸附溶液中的离子，从而形成带电的胶粒。
    2. 金属氢氧化物和金属氧化物通常带正电（氢氧化铁胶体粒子带正电）。
    3. 非金属氧化物和金属硫化物通常带负电。
    4. 淀粉等不带电，大量羟基保证其相对稳定。
4. 胶体的**吸附性**。胶体粒子具有很大的比表面积，能吸附水中悬浮颗粒物使其沉降。
5. 胶体的**电泳**。在外加直流电场的作用下，带电的胶体粒子或离子向着与其电性相反的电极移动，称为电泳。应用：静电除尘。
6. 胶体的**聚沉**。当胶体粒子遇到带有相反电荷的离子或其他胶体粒子时，由于电荷的中和，聚集成为较大的颗粒物，在重力作用下形成沉淀析出。加热、搅拌也能引起胶体的聚沉。应用：制豆腐、形成三角洲等地貌。
7. 纳米材料的应用。

按照胶体分散剂分类：

- 液溶胶（氢氧化铁胶体）。
- 气溶胶（云、雾）。
- 固溶胶（有色玻璃）。

## 氢氧化铁胶体制备

- 化学方程式： $\ce{FeCl3 + 3H2O(沸水) \xlongequal{\Delta} Fe(OH)3(胶体) + 3HCl}$。
- 制备方法：烧杯加入蒸馏水加热至沸腾，将饱和 $\ce{FeCl3}$ 溶液分多次缓慢加入，用玻璃棒轻轻搅拌，继续加热至刚好变成红褐色，停止加热（防止聚沉）即可得到 $\ce{Fe(OH)3}$ 胶体。
- 可以用丁达尔效应证明 $\ce{Fe(OH)3}$ 胶体已经形成。

半透膜：小分子、离子能通过而胶体粒子不能通过的膜，这种现象叫做渗析。而滤纸只能过滤浊液，胶体粒子可以透过滤纸。
