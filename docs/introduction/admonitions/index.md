# 提示框

提示框是用于突出重要信息的标注框。

## 基础提示框

!!! note "笔记"
    这是一个笔记提示框，用于一般信息。

!!! abstract "摘要"
    这是一个摘要提示框，适合用于总结。

!!! info "信息"
    这是一个信息提示框，用于提供有用的说明。

!!! tip "小提示"
    这是一个小提示框，适合分享技巧和最佳实践。

!!! success "成功"
    这是一个成功提示框，用于表示操作成功。

!!! question "问题"
    这是一个问题提示框，适合常见问题解答。

!!! warning "警告"
    这是一个警告提示框，用于重要提醒。

!!! failure "失败"
    这是一个失败提示框，用于表示操作失败。

!!! danger "危险"
    这是一个危险提示框，用于严重警告。

!!! bug "缺陷"
    这是一个缺陷提示框，用于报告问题。

!!! example "示例"
    这是一个示例提示框，适合展示代码示例。

!!! quote "引用"
    这是一个引用提示框，用于引用内容。

## 可折叠提示框

??? note "点击展开"
    此内容默认隐藏。点击标题即可展开查看。

???+ note "默认展开"
    此内容默认可见。点击标题即可折叠隐藏。

## 嵌套提示框

!!! warning "重要配置"
    开始之前，请确保具备以下条件：
    
    ???+ note "前置条件"
        - Python 3.8+
        - 已安装 Git
        - 网络连接
    
    ??? success "可选"
        - Docker（用于容器化部署）
        - Redis（用于缓存）

## 带代码的提示框

!!! example "配置示例"
    ```yaml
    theme:
      name: material
      features:
        - navigation.tabs
        - navigation.sections
        - search.highlight
    ```

!!! tip "最佳实践"
    部署前务必在本地测试文档：
    ```bash
    mkdocs serve
    ```
