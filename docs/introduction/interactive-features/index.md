## 表情符号

MkDocs Material 在整个文档中支持表情符号：

- ✅ 成功和完成
- ❌ 错误和失败
- ⚠️ 警告和注意
- ℹ️ 信息和说明
- 🔧 工具和配置
- 🚀 性能和速度
- 🎨 设计和界面
- 🔒 安全功能
- 📊 分析和数据
- 🌐 网络和连接

## 图标

你可以在文档中使用 Material Design 图标：

- :material-heart: 喜欢和收藏
- :material-star: 评分和星标
- :material-download: 下载
- :material-upload: 上传
- :material-settings: 设置
- :material-account: 用户账户
- :material-lock: 安全锁
- :material-shield: 安全防护
- :material-rocket: 启动和部署
- :material-bug: 缺陷和问题

## 键盘快捷键

使用 `kbd` 标签显示键盘快捷键：

- 按 :kbd:`Ctrl` + :kbd:`C` 复制
- 按 :kbd:`Ctrl` + :kbd:`V` 粘贴
- :kbd:`Ctrl` + :kbd:`S` 保存文件
- :kbd:`Ctrl` + :kbd:`F` 打开搜索
- :kbd:`Ctrl` + :kbd:`Z` 撤销上一步操作

## 高亮文本

你可以使用 mark 扩展来==高亮重要文本==。

使用高亮来引起读者对==关键概念==和==重要信息==的注意。
