# MkDocs Material 功能展示

欢迎来到 MkDocs Material 功能展示页面！这里演示了 Material for MkDocs 主题的各项强大功能。

## 🚀 快速开始

!!! info "开始使用"
    本演示展示了 mkdocs-material 提供的各种功能。通过导航栏浏览不同分类，探索各种能力。

## ✨ 功能分类

- **代码高亮** - 多语言语法高亮
- **提示框** - 用于笔记、警告和提示的精美标注框
- **标签页** - 使用标签页组织内容
- **数学支持** - LaTeX 数学表达式
- **图表** - Mermaid.js 图表支持
- **任务列表** - 交互式复选框
- **表格** - 高级表格格式
- **图标与表情** - Material Design 图标和表情符号

## 🎯 导航功能

- **标签导航** - 在板块之间轻松切换
- **搜索** - 快速客户端搜索，支持高亮
- **深色/浅色模式** - 一键切换配色方案
- **响应式设计** - 适配所有设备尺寸
