# 数学

这里记录数学学习的相关笔记与资料。内容由校本学案整理而成，按知识板块合并为四个部分，每部分内部再按学案顺序分章。

| 部分 | 主要内容 | 入口 |
|:---|:---|:---|
| 集合与逻辑 | 集合的概念、表示与运算，命题与充要条件，反证法 | [集合与逻辑](sets-logic.md) |
| 函数 | 不等式的性质与解法、函数的概念与性质、幂函数 / 指数函数 / 对数函数、函数综合 | [函数](functions.md) |
| 三角 | 任意角与三角函数、三角恒等变换、解三角形、三角函数的图象与性质 | [三角](trigonometry.md) |
| 平面向量与复数 | 向量的概念与线性运算、数量积与常用结论、复数的概念运算与三角形式 | [平面向量与复数](vectors-complex.md) |

## 学习建议

- 先看每章开头的概念与性质，再对照例题检验是否会用；
- 表格中的图象、结论建议自己动手画一遍、推一遍，比死记更牢；
- 标注"易错""说明"的地方，多是作业里反复出错的位置。
